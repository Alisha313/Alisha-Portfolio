# Alisha Patel

Senior software engineer portfolio. Healthcare and health insurance systems in Java, Spring Boot, Kafka, PostgreSQL, and AWS.

Live site: https://alisha313.github.io/Alisha-Portfolio/

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

GitHub Pages deploys the Vite build from the `main` branch. The site base path is `/Alisha-Portfolio/`.
